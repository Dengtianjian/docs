## 组成

| 区域 | 使用组件 | 说明 |
| --- | --- | --- |
| 品牌面板 | 原生布局 | 品牌标记、价值说明与引语 |
| 登录表单 | `KForm` / `KFormItem` / `KInput` | 邮箱、密码与提交 |
| 辅助区 | `KCheckbox` / `KDivider` / `KButton` | 记住我、忘记密码与第三方登录 |

## 复制后替换

1. `model` 与 `rules` 是表单契约；替换成业务登录字段时，同步维护字段名、校验规则与提示文案。
2. `onSubmit` 当前只设置 `logged`；接接口时在这里发请求，成功后跳转，失败时把错误挂回表单或显示 KAlert。
3. 品牌面板文案与三条能力说明可以直接删改；不想要左栏时把 `.panel` 改为单列布局。
4. 真实项目需要 HTTPS、Cookie / Token 策略与 CSRF 处理，示例不包含这些安全策略。

## 注意

- 示例把 KButton 的 `native-type` 设为 `submit`，由 KForm 拦截原生提交并做整表校验；不要把按钮放到 form 外再手动 `validate`，否则会失去回车提交。
- 「记住我」只绑定布尔值，不负责持久化；接业务时再决定存 localStorage、Cookie 还是服务端会话。
- 第三方登录按钮不要复用主登录的 loading 状态，避免两个入口互相锁死。
