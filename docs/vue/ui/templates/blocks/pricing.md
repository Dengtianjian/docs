> 模板类型：区块（Blocks） · 套餐对比。三档 KCard 卡片，包含推荐标记、价格、CTA 与功能清单，窄屏自动纵向排列。

## 组成

| 区域 | 使用组件 | 说明 |
| --- | --- | --- |
| 标题区 | 原生布局 | 模块标题、说明与价格标记 |
| 套餐卡 | `KCard` | 三档方案，推荐档使用 elevated 变体 |
| 推荐标记 | `KTag` | 最受欢迎标签 |
| 操作 | `KButton` | 每档独立的 CTA |
| 功能清单 | `KDivider` + 原生列表 | 按方案展示能力差异 |

## 复制后替换

1. `plans` 是唯一数据源；每项保留 `name / price / unit / cta / featured / features` 即可。
2. 推荐档的视觉由 `featured` 同时驱动 `KTag`、`KCard` 变体与按钮类型；只改一处会出现标记与外观不一致。
3. 需要月付 / 年付切换时，在 `price` 与 `unit` 上接一个 `billing` 状态，不要复制三份卡片。
4. `@click` 目前没有绑定；接业务时给每档 CTA 加跳转或开通逻辑。

## 注意

- 卡片等宽由 CSS Grid 控制，KCard 默认不强制等高；示例用 `height: 100%` 让三张卡在桌面端对齐。
- 演示价格是静态字符串；真实价格计算请保持数值字段，展示时再格式化。
- 如果套餐超过三项，优先改成两列或轮播，不要继续压缩卡片内边距。
