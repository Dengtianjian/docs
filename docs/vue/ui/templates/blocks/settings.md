# 通知设置

> 模板类型：区块（Blocks） · 设置区块。左侧消息开关，右侧免打扰时段与保存动作，适合嵌在账户设置页。

## 组成

| 区域 | 使用组件 | 说明 |
| --- | --- | --- |
| 模块头 | `KTag` | 设备范围与免打扰状态 |
| 消息通知 | `KCard` / `KSwitch` | 四类通知的独立开关 |
| 免打扰 | `KCard` / `KSwitch` / `KSelect` | 开关、开始/结束时间与时长 |
| 保存 | `KButton` | 当前只显示保存提示，接业务时提交接口 |

## 复制后替换

1. `preferences` 是通知项数据源；每项保留 `key / title / description / enabled`，接接口时把 `enabled` 换成服务端值。
2. `quietStart` / `quietEnd` 目前是小时字符串；真实业务如果需要分钟粒度，把 `hourOptions` 换成时间选择器或 15 分钟步进选项。
3. `quietDuration` 已经处理跨天场景（22:00 → 08:00）；保存前仍要在服务端校验一次时段。
4. `save` 只负责提示；接入时改为调用接口并根据结果重置 `saved` 状态。

## 注意

- 设置项之间没有联动，避免一个开关误改其他偏好；如果业务需要「关闭全部」，额外加一个总开关并写明优先级。
- 免打扰关闭时保留时间值，方便用户重新开启时恢复上次设置。
- 移动端下两栏改为单列，消息通知列表在卡片内部自然撑高。
