# 模板（Templates）

> 用 K UI 已落地组件拼出来的完整页面与常用区块。每一份都是单文件 SFC，页面上点「查看代码 / 复制代码」就能拿走，不引入新的包导出或抽象层。

## 页面与区块

| 类型 | 说明 | 当前模板 |
| --- | --- | --- |
| 页面（Pages） | 带完整信息层级与页面容器的模板，可直接作为路由页起点 | [数据看板](./pages/dashboard.md)、[成员管理](./pages/members.md)、[移动端确认订单](./pages/mobile-order.md) |
| 区块（Blocks） | 可嵌入任意页面的功能区块，按业务场景组合 | [登录](./blocks/login.md)、[定价方案](./blocks/pricing.md)、[通知设置](./blocks/settings.md) |

## 怎么用

1. 打开模板页，展开「查看代码」确认依赖组件，再点「复制代码」。
2. 粘贴为业务项目中的 `.vue` 单文件；示例内的 mock 数据、按钮文案与路由跳转都集中在 `<script setup>` 顶部，先替换这些。
3. 保持 `kit/vue/ui/components/*/*.vue` 单文件导入即可；如果项目已接 `KResolver`，可以把导入换成全局组件名。
4. 主题、亮暗、移动端尺寸继续由 K UI token 控制；示例只写布局与业务样式，不覆写组件内部变量。

## 约定

- **模板不是组件**：没有额外的 `KXxxTemplate` 导出，也不承诺跨项目 API 稳定；它们是可读、可改的起点代码。
- **复制即完整**：样式写在同一个 SFC 的 `<style scoped>` 里，复制一个文件即可还原外观；图片位使用色块/文字占位，不依赖外部资源。
- **数据与交互可替换**：表格、图表、表单数据都在示例内声明，接入时换成接口返回即可。
- **优先用组件能力**：弹窗、下拉、移动端弹层等直接使用 K UI 的交互语义，不在示例里重造键盘与焦点逻辑。
