# K UI 全局样式规格（Design Tokens 之上的视觉规则）

> 状态：纸面规格 v0.2。定位：只管「界面长什么样」——色彩、布局、字体、图标、阴影、动效的具体规则与数值；
> 不写价值观与交互模式（后置）。变量实现见 [theme-tokens.md](./theme-tokens.md)（下称 token 规格），逐节互相引用。
> 参考体系：Ant Design 设计规范（antd spec，引用页注明）；采纳/偏离差异登记在 §9。

## 0. 分层关系

```
本文档（视觉规则）：角色与用法 —— "分割线用 colorSplit，边框 1px，间距落 8 网格"
        ↓ 每个规则名词 = token 规格中的一个 alias/map 变量
token 规格（实现层）：数值与派生 —— "--k-color-split: color-mix(in oklab, …)"
        ↓ 每个变量 = 组件部件变量的默认值
组件库：只引用变量，零硬编码
```

新增视觉规则的准入流程：本文档加条款 → token 规格加变量定义 → 组件消费，三步缺一视为未实现。

## 1. 色彩

参考 antd spec [colors-cn]、[dark-cn]：

### 1.1 品牌色与功能色

- **品牌色**：取色板第 6 级为主色（antd 规则采纳），默认拂晓蓝 `#1677FF`；应用范围 = 关键行动点、操作状态、重要信息高亮、图形化，**不铺大面积**；
- **功能色**：成功 `#52C41A`、警告 `#FAAD14`、错误/危险 `#FF4D4F`、信息与链接 = 主色（token 规格 §2 seed 一致）。同一套体系内功能色语义固定，只允许换色值；
- **色板**：12 套基础色板降级为静态工具产物（`getColorPalette()`，token 规格 §4.6），组件运行时只消费 6 组语义色的 CSS 表达式派生；
- **色彩模型**：antd 的 HSB 偏好落地为 **oklab 插值**（感知均匀、纯 CSS 可派生），视觉差异列入校准轮（§9 D1）。

### 1.2 中性色（antd 基线，低段整体调浅）

| 角色 | 亮色 | 暗色 | token |
| --- | --- | --- | --- |
| 标题/一级文本 | `#000000E0`（α0.88） | `#FFFFFFD9` | `colorText` |
| 二级文本 | `#000000A6`（α0.65） | `#FFFFFFA6` | `colorTextSecondary` |
| 三级/占位 | `#00000073`（α0.45） | `#FFFFFF73` | `colorTextTertiary` |
| 禁用文本 | `#00000040`（α0.25） | `#FFFFFF40` | `colorTextQuaternary` |
| 一级边框 | `#E1E2E5`（8% 灰 + 2% 主色） | `#25272B` | `colorBorder` |
| 分割线 | `#0505050F`（α0.06，随边框降档） | `#FDFDFD0F` | `colorSplit` |
| 布局背景 | `#F4F6F9`（2% 灰 + 2% 主色） | `#1B1C20` | `colorBgLayout` |

实现走 `color-mix(…, transparent α)`（token 规格 §4.2，与 antd rgba 方案同构）；`colorBorder` 为实色初始值，可被 tinted neutral 覆盖（§9 D2）。

### 1.3 层级与对比规则

- 文本层级差 = **一级 α 台阶 + 至多一级字阶**，禁止只靠微弱色差分层级；
- 一个视图内品牌色面积 ≤ 操作反馈所需最小面积；大面积优先中性色；
- 无障碍：正文/标题对背景对比度 ≥ 7:1（AAA，antd 字体页要求），组件验收跑对比度单测（token 规格 §7-4）。

### 1.4 暗色

规则采纳 antd [dark-cn]：避免强对比（舒适性）、层级关系不翻转（一致性）；
实现 = `light-dark()` 基线翻转 + 暗段色板参考例值（bg `#141414`、primary 暗段 `#177DDC` 系）校准（token 规格 §7）。

## 2. 布局与栅格

参考 antd spec [layout-cn]：

- **网格基数 8**：布局层尺寸全部为 8 的倍数；组件内部允许 4px 半格（token 规格 `step = 4`，微观间距：图标间隙、paddingXXS）——「布局 8、微观 4」双粒度；
- **常用模度**：`[8,16,24,32,40,48,56,64,72,80,96,144…]` 为布局间距/区块尺寸决策表，映射 `size*/padding*/margin*` 阶梯（token 规格 §5.3）；
- **24 栅格 + Gutter 定值**：Row/Col 24 列；断点变化时 **Gutter 固定、Column 流动**（antd 规则采纳）；PC 侧 Gutter 推荐 `16/24/24/24/24/24`（xs~xxl）；
- **断点与容器**：`xs<576 | sm≥576 | md≥768 | lg≥992 | xl≥1200 | xxl≥1600`；内容区最大宽度 = 断点值 − 双侧留白最小值；
- **画板与适配**：PC 统一画板 **1440**；主流分辨率 1920/1440/1366/1280；两种标准适配：左右布局 = 左栏固定 + 右区缩放（后台默认）；上下布局 = 留白定最小值 + 中区缩放（门户/详情）；
- **移动端布局**（K UI 补充）：<768 弃用 24 栅格，流式单列 + 16px 页边距（`padding` mobile 覆盖，token 规格 §8.2）；全宽卡片/列表优先，栅格仅 ≥md 生效；
- antd 结语采纳为条款：**网格与模度是启发，不是限制**——允许场景内偏移，但偏移必须能用「为什么这块破了格」解释。

## 3. 字体

参考 antd spec [font-cn]：

- **字体族**：`-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, 'Noto Sans', sans-serif, 'Apple Color Emoji', 'Segoe UI Emoji', 'Segoe UI Symbol', 'Noto Color Emoji'`；代码字体 `SFMono-Regular, Consolas, 'Liberation Mono', Menlo, monospace`；
- **主字体 14 / 行高 22**（≈1.5714）；基于 50cm 阅读距离与 0.3° 视角（antd 论证采纳）；
- **字阶**：10 级派生公式见 token 规格 §5.1；**单个系统实际使用控制在 3~5 档**（antd 建议升为约束，§9 D6）。推荐组合：正文 14 / 辅助 12 / 强调 16，标题走 heading 阶跳跃使用；
- **字重**：仅 400（regular）与 500（medium）；英文加粗 600（semibold）；不提供 700+（中文屏显发糊）；
- **数字**：数字参与纵向对比处必须 `font-variant-numeric: tabular-nums`（InputNumber/Statistic/Descriptions/时间类内置；utility `k-tabular-nums` 供业务）；
- 中英文/数字混排：全角标点不插空格、半角括号与中文间加一个空格（CSS 可解部分交排版 utility，其余进文案组件默认行为）。

## 4. 图标

参考 antd spec [icon-cn]。K UI 策略：**采纳设计规范，收编既有图标集，不养图标设计线**：

- **规格采纳**：1024 画板、64 出血位、偶数原则（去小数点）；元素韵律——点 16 倍数（80/96/112/128）、线 8 倍数（56/64/72/80）、圆角 8 倍数三档（8/16/32）、三角 ≈76°、曲/斜线 +4px 视觉补偿；
- **落地**：基础集候选 = Remix Icon / Solar / 自绘核心 60 枚 + 开源补齐（待定项 Q1）；统一经 `KIcon` 注入：`currentColor` 随文本色级，尺寸四档 14/16/24/32（`sizeIcon*`）；
- **使用规则**：表意不确定就不用图标；同一动作全库同一图标（图标-动作映射表进文档站）。

## 5. 尺寸与圆角

- 控件高度：PC 26/30/34/38 四档（默认 34 = lg 38 的 89%）；移动端 36/40/**44**/52（触达最小 44，token 规格 §5.4、§8.2）；
- 圆角：基数 6 派生阶梯（none/xs/sm/base/lg/xl/full，token 规格 §5.2）；默认 antd 系 6px 风格，移动端整体升一档（8px）；圆形仅头像/图标按钮/胶囊标签（`shape` 轴表达，不开自由值）。

## 6. 阴影

参考 antd spec [shadow-cn]，2026-11-20 全局调浅约 40%：

- **四层高度模型**：0 层无阴影（输入框等贴合面）→ 1 层低（hover 临时悬浮）→ 2 层中（展开跟随：下拉/气泡）→ 3 层高（独立：对话框/抽屉/通知）；**z-index 档位与阴影档位强制一一对应**（token 规格 §5.5 映射表）；
- **三层叠加柔和阴影**（alias 初值）：

| token | 亮色初值 | 组件消费方 |
| --- | --- | --- |
| `--k-box-shadow`（1-down） | `0 6px 16px 0 rgba(0,0,0,.05), 0 3px 6px -4px rgba(0,0,0,.08), 0 9px 28px 8px rgba(0,0,0,.03)` | Select/Menu 弹层、Card hover |
| `--k-box-shadow-secondary`（2） | `0 1px 2px -2px rgba(0,0,0,.10), 0 3px 6px 0 rgba(0,0,0,.07), 0 5px 12px 4px rgba(0,0,0,.05)` | Dropdown、Popover、Drawer |
| `--k-box-shadow-tertiary`（3） | `0 3px 6px -4px rgba(0,0,0,.08), 0 6px 16px 0 rgba(0,0,0,.05), 0 9px 28px 8px rgba(0,0,0,.03)` | Modal、Notification |

- **方向语义**：向下=常规浮层；向上=底部导航/工具栏（各档含 up/left/right 变体，rgba 同表换符号）；向左/右=侧栏、固定列表格列；
- 暗色：α 上调一档（token 基线补丁），不走 Material 描边海拔路线（§9 D3）。

## 7. 动效

参考 antd spec [motion-cn]：

- **三原则采纳**：自然（视觉连贯、动作成立）、高效（**出场快于进场**，批量退场整体消失不排队）、克制（非主要元素不配动效）；
- 时长：`fast 0.1s / mid 0.2s / slow 0.3s`（motionUnit 派生）；浮层收起 fast、展开 mid；
- 曲线：`easeInOutCubic cubic-bezier(.645,.045,.355,1)` 展开收起对称、`easeOutQuint (.23,1,.32,1)` 入场、`easeInQuint (.755,.05,.855,.06)` 退场；
- **方向规则**：浮层从触发元素方向进入（下拉向下、Tooltip 随 placement）；遮罩类 PC 中心缩放、移动底部滑入（与双形态组件对应）；
- 移动端差异走 token：mid 时长 +0.1s（token 规格 §8.2）；**不使用回弹曲线**（`easeOutBack` 保留为业务二开备用值，库内不消费），弹跳/涟漪类动效一律不进库；
- loading 旋转统一 **1s linear**（`--k-motion-duration-spin`，antd `loadingCircle` 与 naive 同值）；
- 整体基调：企业级、通用、大众、现代——状态反馈只做「颜色加深/变浅」一条路，不靠位移与形变表达按下。
- 每条动效必须能回答「它解释了什么空间/状态关系」，答不出就删（克制原则的验收问句）。

## 8. 数据展示格式

参考 antd spec [data-format-cn]，沉淀为 `utils/format` 默认值（供 InputNumber/Statistic/时间类组件调用，业务可覆盖）：

- 时间：列表 `YYYY-MM-DD HH:mm`；同日记录折叠为 `HH:mm`；相对时间仅在提示场景（「3 分钟前」）；
- 金额/数字：右对齐 + 千分位 + 固定小数位 + `tabular-nums`；
- 大数缩写：中文语境 `1.2万 / 3.4亿`（K/M 的本地化替换，§9 D4）；
- 空值：统一 `--`；状态：文字为主、色彩为辅（不允许只用颜色表达状态，色盲场景失效）。

## 9. 对 antd spec 的采纳/偏离登记表

| # | 议题 | antd 方案 | K UI 决策 | 理由 |
| --- | --- | --- | --- | --- |
| D1 | 色彩模型 | HSB + 调色板算法 | oklab（CSS `color-mix`） | 感知均匀、纯 CSS 派生免 JS；差异列入校准轮 |
| D2 | 边框色 | `#E1E2E5`（8% 灰 + 2% 主色） | antd `#D9D9D9` 为基线，低段整体调浅 | tint=0 回到纯灰 8%，默认 0.02 |
| D3 | 暗色层次 | 阴影加深 + 暗段色板 | 同（不走 Material 描边/海拔） | 与亮色同一层级语言 |
| D4 | 数字缩写 | K/M | 万/亿，可配 | 中文语境 |
| D5 | 12 套基础色板 | 全量提供 | 6 组语义 + 静态色板工具 | 组件不需要 12 色；可视化色板后置 |
| D6 | 字阶 10 级 | 定义 10 级 | 派生保留，使用限 3~5 档 | antd 建议升为约束 |
| D7 | 断点 lg | 992 | 992 | 与 antd 生态一致 |
| Q1 | 图标集来源 | 自设计 | 待定：收编开源集 vs 自绘核心集 | 需设计投入评估 |
| Q2 | 空状态插画 | antd 插画体系 | 待定：先用几何 SVG，插画后置 | 避免早期绑死风格 |
| Q3 | 可视化色板 | AntV 规则 | 后置（图表批次） | 不阻塞组件线 |
